## 📂 Projects

### 🏠 [BuBot](https://github.com/naluteo89-sketch/BuBot) · 부동산 매매가 RAG 챗봇
자연어 질문으로 전국 245개 지역 × 176개월 아파트 평균 매매가를 조회·비교하고, **계산 근거와 출처**를 함께 보여주는 챗봇
- 숫자는 Python이 계산, GPT는 해석·문장만 담당하도록 역할 분리
- 실제 API 30문항 정확도 **80% → 100%**, 자동 테스트 **191개** 통과
- 벡터 저장소(SQLite + numpy)·웹 서버 직접 구현, 예산·호출 제한으로 비용 제어

### 📸 [ImgPls](https://github.com/naluteo89-sketch/ImgPls) · AI 이미지 합성 스튜디오
인물 사진과 배경 테마를 고르면 ComfyUI(FLUX.2)로 자연스럽게 합성하고, QR로 휴대폰에 전달하는 행사장용 키오스크 서비스
- 무거운 생성은 GPU 서버에, 웹 서버(FastAPI)는 중계·저장·공유만 담당
- 모의 ComfyUI 서버로 생성 파이프라인 전체 검증, API 테스트 10종
